# 单独导出平时分

在考勤记录页的现有导出区增加“导出平时分”，复用下载弹窗及课程/班级筛选。新增 GET /courses/{course_id}/scores-export，按班级生成 Excel 工作表，包含序号、课程、班级、学号、姓名、平时分、名单状态及评价状态。

权限沿用课程归属校验，分数仅来自 get_book 的 final_score，不重复计算；保持学号文本、成绩数值和小数两位格式。未评按现有规则计零并保留评价状态，缺少规则时阻止导出，没有学生时明确提示。无考勤场次也能导出成绩，不受考勤列表筛选影响。

验证：先编写失败的服务与按钮交互测试，实现独立服务、接口和按钮后，检查多班级、单班筛选、权限及规则缺失；运行导出专项测试、前端记录页测试、类型检查、构建和浏览器下载回归。
