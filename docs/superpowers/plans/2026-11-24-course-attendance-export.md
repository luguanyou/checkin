# 课程考勤汇总导出

目标：在考勤记录页选择课程后，一次下载该课程所有已完成考勤，按班级分表，学生为行，场次为列。

设计：新增 GET /api/v1/courses/{course_id}/attendance-export，生成 Excel。可选 class_group_id 限定一个班级；不受列表日期、状态或分页影响。按日期、开始时间、ID 排序，同日多次课各占一列。学生按历史记录 student_id 合并，采用最近场次的身份快照，不依赖当前有效名单。缺少记录留空；待确认显示“待确认”。保留单次导出。权限沿用课程归属校验。

参考表的出勤、请假、缺勤符号用于新表（√、O、×），迟到用“迟”；系统没有独立病假状态，不推断病假。不生成无来源的成绩。
