# 学生名单弹窗新增

在学生名单页面提供“新增学生”按钮。弹窗填写学号（50 字）、姓名（100 字），必填并去除首尾空格；性别（20 字）、专业（120 字）选填。

POST /api/v1/classes/{class_group_id}/roster 保存学生与班级关系。限制为当前教师所属且未归档的课程、班级。学号全局唯一：已有学生沿用原资料，姓名不一致拒绝保存；当前成员重复提交返回 409；已移除成员恢复原关系，保留历史记录。事务保存并写入审计日志，唯一约束冲突返回可读错误。

保存期间防止重复提交或关闭。失败保留输入并显示错误；成功关闭弹窗、刷新名单和班级人数，重置搜索、分页及状态为当前成员。批量导入继续使用原流程。

验证：前端交互测试覆盖新增、错误后重试、保留输入、成功关闭；后端测试覆盖新增、去空格、重复拒绝、恢复及必填校验。生产构建和 Ruff 检查通过。MySQL 集成测试需启动测试数据库后运行。
