# 班级及关联考勤数据删除设计

## 目标

允许教师删除已有名单或考勤数据的班级。删除属于不可恢复操作，必须由用户在前端明确确认，并由调用方通过 API 参数明确请求级联删除。

## 删除范围

删除班级时永久删除以下数据：

- 该班级的全部考勤明细；
- 该班级的全部考勤场次；
- 该班级的全部名单关系；
- 该班级的导入预览记录；
- 班级本身。

不删除学生基础档案。学生可能同时属于其他班级，其档案和其他班级中的名单、考勤数据必须保持不变。课程也不随班级删除。

## 前端交互

教师点击“删除班级”后，浏览器显示确认提示：

> 确定删除班级“{班级名称}”吗？该班级的学生名单和全部历史考勤记录将永久删除，且无法恢复。

用户取消时不发送删除请求。用户确认后，前端调用级联删除接口，并在请求期间禁用删除按钮。成功后提示“班级及关联数据已删除”并刷新课程列表；失败时展示后端返回的错误信息。

## API 契约

保留现有端点：

```http
DELETE /api/v1/classes/{class_group_id}?delete_related_data=true
```

- 空班级可继续通过不带参数的现有请求删除。
- 班级存在名单、考勤或导入预览时，不带 `delete_related_data=true` 的请求继续返回 `409 RESOURCE_STATE_CONFLICT`。
- 只有班级所有者可以删除；非所有者仍返回 `404 RESOURCE_NOT_FOUND`，避免泄露资源存在性。
- 成功返回 `204 No Content`。

前端确认后始终携带 `delete_related_data=true`，使用户意图能够传递到服务端，而不是依赖客户端提示作为唯一保护。

## 服务端事务

服务层先验证班级归属，再统计关联数据。收到显式级联参数后，在同一数据库事务内按外键依赖顺序执行：

1. 删除属于该班级考勤场次的考勤明细；
2. 删除该班级的考勤场次；
3. 删除该班级的导入预览记录；
4. 删除该班级的名单关系；
5. 写入班级删除审计记录，包含被删除数据的数量摘要；
6. 删除班级并提交事务。

任一步失败时回滚整个事务，避免留下部分删除状态。实现使用显式删除语句，不修改数据库外键为级联删除，以便删除范围清晰可审计。

## 测试

后端测试覆盖：

- 空班级保持可删除；
- 有名单或考勤时，不带显式参数仍被拒绝；
- 带显式参数可删除名单、考勤场次、考勤明细和导入数据；
- 学生基础档案、课程、其他班级及其数据不受影响；
- 非所有者不能级联删除。

前端测试覆盖：

- 确认提示包含名单、历史考勤、永久删除和不可恢复信息；
- 取消确认时不调用 API；
- 确认后调用带级联参数的删除方法；
- 成功后刷新课程列表并显示成功提示。
