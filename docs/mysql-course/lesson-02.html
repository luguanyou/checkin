字段类型：规定可以保存什么

类型本课怎么用示例
INT整数形式的内部编号1、2、3
VARCHAR(20)最多20个字符的学号001、2026A01
VARCHAR(50)最多50个字符的姓名张晨

选类型，看数据的含义，不只看它长得像不像数字。

教师备注 · 备课与面试延伸VARCHAR(n)中的n表示最大字符数，不是“必须填满n位”。字节数与字符集有关，学生层不深入。

LESSON 02 / 认识与理解

四条规则，让脏数据进不来

写法含义用在哪里
PRIMARY KEY唯一、非空地标识一行id
AUTO_INCREMENT未指定编号时自动分配id
NOT NULL不能缺少该字段值学号、姓名
UNIQUE不允许相同值重复出现学号

NOT NULL 不等于“不能输入空字符串”。姓名为空白还需要其他校验。

教师备注 · 备课与面试延伸说明同名学生可能存在，不能把name设置为唯一。主键与学号唯一约束各有角色。

LESSON 02 / 教师演示

完整 SQL：建立学生表

CREATE TABLE students (
  id INT PRIMARY KEY AUTO_INCREMENT,
  student_number VARCHAR(20) NOT NULL UNIQUE,
  name VARCHAR(50) NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

括号里定义字段，字段之间用英文逗号，整条语句用分号结束。

教师备注 · 备课与面试延伸逐行运行前先完整读一遍：表名、字段、类型、约束、引擎、字符集。InnoDB后续支持外键与事务，此处只说明用途。
