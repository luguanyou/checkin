# 课点管理员与教师使用教程

本文面向课点考勤系统的超级管理员和任课教师，说明当前系统内已经提供的全部用户功能及操作方法。页面在电脑和手机浏览器上都可以使用；课堂点名时建议使用带键盘的电脑，并优先使用 Chrome 或 Edge，以获得较稳定的语音播报体验。

## 1. 角色与功能范围

| 功能 | 超级管理员 | 教师 |
| --- | --- | --- |
| 登录、退出 | 支持 | 支持 |
| 创建、搜索和筛选教师账号 | 支持 | 不支持 |
| 停用、启用教师账号 | 支持 | 不支持 |
| 重置教师密码 | 支持 | 不支持 |
| 查看工作台 | 不支持 | 支持 |
| 管理课程和班级 | 不支持 | 支持，仅限自己的数据 |
| 导入和维护学生名单 | 不支持 | 支持，仅限自己的班级 |
| 发起和完成课堂点名 | 不支持 | 支持 |
| 查询、修正和导出考勤 | 不支持 | 支持 |
| 录入积分、配置基础分、汇总和导出平时成绩 | 不支持 | 支持，仅限自己的班级 |

管理员登录后只进入“教师账号”管理页，不能进入教师业务页面。教师只能查看和操作自己创建的课程、班级、名单、考勤记录与平时成绩。

## 2. 登录、首次改密与退出

### 2.1 登录

1. 使用浏览器打开系统地址。
2. 在“用户名”中输入管理员或教师用户名。
3. 在“密码”中输入对应密码。
4. 单击“登录”。

登录成功后，管理员会进入“教师账号”页，教师会进入“工作台”。系统提示“用户名或密码错误”时，请检查用户名和密码；已停用的教师账号也无法登录，并会得到相同提示。

### 2.2 教师首次登录或密码被重置后改密

教师使用临时密码登录后，系统会直接打开“设置新密码”页，改密完成前不能使用其他功能。

1. 在“当前密码”中输入管理员提供的临时密码。
2. 输入新密码。密码长度必须为 12 至 128 个字符，且不能与当前密码相同。
3. 在“确认新密码”中再次输入新密码。
4. 单击“保存并进入工作台”。

两次新密码不一致或当前密码错误时，按页面提示重新输入。改密成功后，除当前浏览器外的其他登录会话会失效。

### 2.3 退出

- 管理员：单击页面右上角“退出登录”。
- 教师电脑端：单击左侧栏底部账号旁的退出图标。

退出后需要重新输入用户名和密码才能进入系统。

## 3. 管理员使用教程

### 3.1 查看教师账号概况

“教师账号”页顶部显示三个统计数字：账号总数、已启用数和已停用数。账号列表显示教师姓名、用户名、账号状态、密码状态和最近登录时间。

“首次登录需改密”表示教师正在使用管理员生成的临时密码；“密码已设置”表示教师已经完成首次改密。“从未登录”表示该账号尚未成功登录过。

### 3.2 搜索与筛选教师

1. 在“搜索教师”中输入教师姓名或用户名的全部或部分内容。
2. 在“账号状态”中选择“全部状态”“已启用”或“已停用”。
3. 系统自动更新结果。结果较多时，使用列表底部的分页按钮翻页。

清空搜索内容并选择“全部状态”可恢复完整列表。

### 3.3 创建教师账号

1. 单击右上角“创建教师”。
2. 填写“教师姓名”，最多 100 个字符。
3. 填写“用户名”，最多 64 个字符。系统会去除首尾空格并转换为小写；用户名不能与已有账号重复。
4. 单击“确认创建”。
5. 创建成功后，在“一次性登录凭据”窗口中单击“复制登录凭据”。
6. 通过可信渠道把姓名、用户名和临时密码交给教师，并提醒教师首次登录后立即修改密码。

临时密码由系统自动生成，只在创建成功后的窗口中显示一次。关闭窗口后不能再次查看，只能执行密码重置。

### 3.4 停用或启用教师账号

1. 在目标教师所在行单击“停用”或“启用”。手机端先展开“账号操作”。
2. 核对教师姓名和用户名。
3. 单击“确认停用”或“确认启用”。

停用后，该教师不能登录，已有登录会话也会立即被撤销。重新启用后，教师可继续使用原密码登录；启用账号不会自动生成新密码。

### 3.5 重置教师密码

教师忘记密码时：

1. 在目标教师所在行单击“重置密码”。
2. 核对教师姓名和用户名，单击“确认重置”。
3. 在操作成功后出现的“一次性登录凭据”窗口中单击“复制登录凭据”。
4. 通过可信渠道把新临时密码交给教师。

重置密码后，该教师的所有现有登录会话会失效。教师需要使用新临时密码登录，并再次完成首次改密。新临时密码同样只显示一次。

### 3.6 管理员账号密码的维护方式

管理员页面目前没有修改管理员自身密码的入口。系统运维人员需要修改服务端 `api/.env` 中的 `ADMIN_PASSWORD`，然后重启 API。管理员密码必须为 12 至 128 个字符。该文件含有明文凭据，不得发送给普通用户或提交到版本控制。

## 4. 教师使用教程

教师电脑端可通过左侧导航进入“工作台”“课程班级”“学生名单”“考勤记录”和“平时成绩”；手机端使用底部导航。“学生名单”导航会打开系统找到的第一个可用班级。需要管理指定班级时，建议从“课程班级”页单击该班级的“管理名单”。平时成绩也可从班级行的快捷入口打开。

### 4.1 使用工作台

工作台提供当天教学概况：

- “进行中课程”：当前未归档的课程数。
- “活动班级”：进行中课程下的活动班级数。
- “近期到课率”：根据近期场次计算的到课情况。
- “课程与班级”：列出可开始点名的活动班级和当前名单人数。
- “最近场次”：最多显示最近 5 个场次，并标记“进行中”或“已完成”。

单击进行中场次可继续点名，单击已完成场次可查看详情。单击“管理课程”可进入课程与班级维护页。

### 4.2 新建课程和班级

先创建课程：

1. 进入“课程班级”，单击“新建课程”。
2. 填写课程名称、课程代码和学期。
3. 单击“创建课程”。

课程名称最多 120 个字符，课程代码和学期各最多 50 个字符。同一教师名下不能存在课程代码与学期都相同的两门课程。

再创建班级：

1. 在目标课程卡片底部单击“新建班级”。
2. 填写班级名称，例如“2026级1班”。
3. 单击“创建班级”。

班级名称最多 120 个字符，同一课程下不能出现同名班级。已归档课程不能新建班级。

### 4.3 查找、编辑、归档和删除课程班级

#### 查找课程

在页面顶部输入课程名称或课程代码，并选择“进行中”或“已归档”。结果较多时使用分页按钮。

#### 编辑名称

- 单击课程卡片中的“编辑课程”可修改课程名称。当前页面不支持修改课程代码或学期。
- 单击班级行中的“编辑”可修改班级名称。

#### 归档与恢复课程

单击“归档课程”可让课程停止用于新建班级、名单修改、新建考勤和平时成绩修改。归档不会删除已有名单、历史考勤和平时成绩。需要继续使用时，在状态筛选中选择“已归档”，找到课程后单击“恢复课程”。

#### 删除班级和课程

删除不可恢复，系统会要求二次确认。操作前务必核对目标：

- 删除班级会同时永久删除该班级的名单关系、名单导入预览、全部历史考勤场次及其考勤记录，以及平时成绩设置、项目和积分记录；系统中的学生基础档案会保留。
- 可从“课程班级”页单击班级行中的“删除”，也可在该班级的“学生名单”页单击顶部“删除班级”。
- 只有已经不包含任何班级的课程才能删除。
- 如需删除课程，必须先逐个删除其中的班级；删除班级时相关历史数据也会被删除。
- 如果只是暂时停用课程并希望保留历史数据，请使用“归档课程”，不要删除班级或课程。

### 4.4 下载并填写学生名单模板

1. 从“课程班级”找到目标班级，单击“管理名单”。
2. 单击“下载模板”，系统下载 `学生名单导入模板.csv`。
3. 使用 Excel 或其他表格软件填写数据，保留表头。

模板字段如下：

| 字段 | 是否必填 | 最大长度 | 填写要求 |
| --- | --- | --- | --- |
| 学号 | 是 | 50 | 每名学生应使用唯一学号 |
| 姓名 | 是 | 100 | 不可留空 |
| 性别 | 否 | 20 | 可留空 |
| 班级 | 是 | 120 | 必须与系统中的目标班级名称完全一致 |
| 专业 | 否 | 120 | 可留空 |

系统支持 `.csv`、`.xls` 和 `.xlsx`，单个文件不能超过 10 MiB，数据不能超过 500 行。CSV 可使用 UTF-8 或 GB18030 编码。除中文表头外，系统也识别部分英文表头，例如 `student_number`、`name`、`gender`、`class_name` 和 `major`。

### 4.5 导入学生名单

1. 在目标班级的名单页单击“导入名单”。
2. 单击“浏览文件”并选择名单文件。
3. 等待系统校验，然后查看总行数、有效数、错误数和重复数。
4. 如果存在错误，查看每行“说明”，修改源文件后单击“重新选择”并再次上传。
5. 如果存在重复学号，选择处理方式：
   - “跳过已有成员”：不改变系统中已有的名单关系。
   - “恢复已移除关系”：当该学号曾从当前班级移除时，将其恢复为当前成员；已经在名单中的成员仍会跳过。
6. 确认错误数为 0 后，单击“确认导入”。
7. 查看新增学生、新增名单、恢复成员和跳过数量，然后单击“完成”。

以下情况会阻止导入：缺少必填表头或字段、字段过长、文件内学号重复、班级名称不匹配，以及同一学号在系统中已对应不同姓名。导入预览有效期为 1 小时，过期后需要重新上传。已归档课程或班级不能导入名单。

### 4.6 搜索、移除和恢复名单成员

名单页可按姓名、学号或专业搜索，并可筛选“当前成员”“已移除”或“全部成员”。

- 单击当前成员行中的“移除”，该学生将不再进入以后新建的点名场次。
- 在“已移除”列表中单击“恢复”，该学生会重新参与以后新建的点名场次。

移除学生不会删除学生档案，也不会改变已经创建或完成的历史点名场次。已归档课程或班级不能修改名单。

### 4.7 开始一次点名

开始前应确认课程和班级处于活动状态，且班级至少有一名当前成员。

1. 在工作台的“课程与班级”中找到目标班级。
2. 核对名单人数，单击“开始点名”。名单为空时按钮不可用。
3. 系统以当天日期创建新场次，并把当前名单复制为本次点名快照。

系统允许同一班级在同一天创建多个场次。若已有未完成场次，优先从“最近场次”或“考勤记录”打开“进行中”场次继续处理，避免误建重复场次。

### 4.8 逐一点名

点名页显示当前学生、处理进度、到课率、同步状态和异常名单。给学生标记状态后，系统立即保存，并自动前进和播报下一位。

| 操作 | 页面按钮 | 键盘快捷键 |
| --- | --- | --- |
| 标记已到 | “已到” | `Space`（空格） |
| 标记缺勤 | “缺勤” | `1` |
| 标记请假 | “请假” | `2` |
| 标记迟到 | “迟到” | `3` |
| 返回上一位 | “上一位” | `Backspace` |
| 前往下一位 | “下一位” | 无 |
| 重新播报当前姓名 | “重新播报” | `R` |
| 静音或开启语音 | “静音”或“开启语音” | `M` |

在输入框、文本框或下拉框中操作时，快捷键不会触发点名。到达最后一位后不会继续越界，可用“上一位”或 `Backspace` 返回并重新标记；重新标记会覆盖该学生当前状态。

右侧“异常名单”实时显示缺勤和迟到学生，请假不会出现在此列表中。页面到课率按已处理学生计算，“已到”和“迟到”计入到课，“待确认”不进入分母。

### 4.9 设置语音播报

- 拖动“语速”滑块可在 `0.5x` 至 `2.0x` 之间调整速度。
- 在“音色”下拉框中选择浏览器和操作系统提供的声音，或使用“系统默认”。
- 单击“静音”可关闭自动播报；单击“开启语音”恢复。
- 语速和音色会保存在当前浏览器中，供下次使用。

浏览器不支持语音时，页面会提示“当前浏览器不支持语音播报”，但按钮和键盘点名仍可正常使用。没有声音时先确认系统音量和页面未静音，再尝试更换音色或使用 Chrome、Edge。

### 4.10 保存失败与继续点名

顶部状态含义如下：

- “全部已同步”：当前变更均已保存到服务器。
- “N 项同步中”：仍有变更正在保存，请暂时不要结束点名或关闭页面。
- “保存失败”：最近一次变更未保存，界面会把该学生恢复到修改前状态。

出现“保存失败”时，检查网络后单击“重新载入”。如果记录已被其他页面更新，系统也会重新读取最新数据。系统没有离线草稿功能，请勿在断网或仍显示“同步中”时关闭页面。

### 4.11 结束点名

1. 建议先确认所有学生都不再显示“待确认”。
2. 确认顶部显示“全部已同步”。
3. 单击右上角“结束点名”。
4. 核对已确认和待确认人数，单击“确认结束”。

当前系统允许在仍有待确认学生时结束场次，因此教师必须在确认窗口中主动核对人数。场次结束后不能恢复为“进行中”，系统会自动进入场次详情页；如有错误，可按“修正考勤状态”的方法处理。

### 4.12 查询考勤记录

进入“考勤记录”后，可以组合以下条件筛选：课程、班级、状态、起始日期和结束日期。选择课程后，班级下拉框只显示该课程的班级；更换课程会清除原班级条件。

列表展示日期、课程、班级、已处理进度、异常数和场次状态：

- 对“进行中”场次单击“继续点名”。
- 对“已完成”场次单击“查看详情”。
- 结果较多时使用底部分页按钮。

### 4.13 查看和修正场次详情

已完成场次详情显示应到、已到、缺勤和迟到人数，以及每名学生的学号、姓名、状态、首次标记时间、最后修改人和最后修改时间。

修正记录：

1. 在目标学生行单击“修正”。
2. 选择“已到”“缺勤”“请假”或“迟到”。
3. 对已完成场次填写修正原因，最多 500 个字符。
4. 单击“确认修正”。

修正成功后，页面会更新状态。若页面提示记录已被其他操作更新，请重新载入页面，核对最新状态后再操作。所有变更均会保留修改人、时间和修正原因等审计信息。

### 4.14 导出考勤记录

只有已完成场次可以导出。

1. 打开已完成场次的详情页。
2. 单击“导出记录”。
3. 选择“Excel 工作簿 (.xlsx)”或“CSV 文本 (.csv)”。
4. 单击“生成文件”。

文件名包含课程、班级、场次日期和“单次考勤”。导出内容包括课程、课程代码、班级、日期、学号、姓名、状态、点名时间、最后修改时间和最后修改人。浏览器若阻止下载，请允许该站点下载文件后重试。

### 4.15 记录平时表现积分

“平时成绩”按班级独立管理，包含作业、课堂表现、上机实验表现和其他四类。同一门课程下，不同班级可以使用不同项目、基础分和换算规则。

1. 进入“平时成绩”，选择课程和班级。
2. 在“项目积分录入”中选择类别，新建具体项目，例如“作业 1”“实验 1”或“9 月 22 日课堂讨论”，填写名称、日期和说明。
3. 在学生列表上方输入学号或姓名，可快速筛选需要录入的学生。
4. 按学生录入本次积分，可使用快捷值，也可输入自定义正负小数及备注。
5. 核对后保存本次录入。保存成功才代表已经写入服务器。

快捷评价按钮为 `1`、`2`、`3`、`4`、`5`，也可以输入自定义正负小数。待评价项目默认按 `0` 分参与汇总，但仍保留“待评价”状态提示；每次独立表现可新建一个项目，记录发生日期和原因。

同一学生同一项目只有一条当前积分，再次录入是修改，不会重复相加。积分最多支持四位小数，不设类别积分上限。切换项目、班级或离开时，应先保存未提交的修改；网络错误时保留页面输入，可重试。

### 4.16 设置基础分与换算系数

在“基础分与换算”中设置并保存：

- **基础分**：初始显示 `70`，可以改为 `60`、`80` 或其他数值，不同班级各自保存。
- **每积分分值**：各类别的 1 积分折合多少成绩分，例如作业 `0.5`、上机实验表现 `1`、课堂表现 `1`、其他 `0.5`。
- 系数不必合计为 100。系数为 `0` 表示该类别不参与总分；留空表示规则还未确定。

换算公式：

```text
类别加扣分 = 类别净积分 × 每积分分值
原始总分 = 基础分 + 所有类别加扣分
最终平时成绩 = 将原始总分限制在 0～100 分
```

每个类别的累计积分和加扣分均不封顶、不保底，只有最终总成绩限制为百分制。举例：基础分 70，作业 16.5 积分乘 0.5，上机实验 8 积分乘 1，课堂净积分 4 乘 1，其他 2 积分乘 0.5，平时成绩为 `70 + 8.25 + 8 + 4 + 1 = 91.25`。若计算结果为 103，页面同时保留原始总分 103 和最终成绩 100。

可以先录积分，学期末再设置换算规则。修改规则会重新计算汇总，原始记录不变。考勤始终独立，不纳入本模块；本模块不录期末成绩，也不乘总评中的 40%。

### 4.17 查询、追溯与导出平时成绩

进入“平时成绩汇总”查看各学生的类别积分、类别加扣分、原始总分和最终成绩。正式总分按两位小数计算展示。

- “规则待配置”：基础分或某个类别系数留空，补齐并保存即可计算。
- “待评完整”：参与总分的项目仍有待评价记录；这些记录按 0 分参与汇总，可在确认后明确录入实际积分。
- 系数为 0 的类别不阻止总分生成。没有项目的类别累计积分为 0。
- 可查看学生成绩的变更记录，核对修改时间、操作者和前后值。

导出支持 Excel 和 CSV，可选择原始项目明细或成绩汇总。规则未配置时仍可导出原始明细；正式汇总需要规则齐全。未评价完整的学生在报表中标明状态，同时按 0 分计入并输出当前总成绩。

名单中已移除学生的历史积分仍可查看和导出，但不能新增或修改；恢复名单后重新允许录入。移除后新建项目不会为该学生追加待评记录。归档课程或班级整体只读，需要恢复后再修改。

如果提示成绩已被其他页面修改，当前版本已过期。请保留本次输入以便核对，重新载入最新成绩后再修改保存，避免覆盖另一页面的工作。

## 5. 常见问题

### 为什么“开始点名”按钮不可用？

班级没有当前名单成员。进入该班级的“管理名单”，导入学生或恢复已移除成员后再试。

### 为什么不能新建班级、导入或修改名单？

课程或班级已归档。到“课程班级”页筛选“已归档”，恢复课程后再操作。

### 为什么班级或课程删除失败？

课程只要仍有班级就不能删除，请先处理其中的班级。删除班级会永久删除该班级的名单、历史考勤和平时成绩；如果操作失败，请刷新页面确认班级仍属于当前账号，再根据页面错误提示重试。需要保留历史数据时请使用归档。

### 为什么名单文件不能确认导入？

预览中存在错误。重点检查必填字段、字段长度、目标班级名称、重复学号和同一学号对应的姓名。也要确认文件不超过 10 MiB、500 行，并在预览生成后 1 小时内确认。

### 为什么点名结束按钮不能确认？

仍有变更正在同步，或发生过保存失败。等待顶部显示“全部已同步”；如显示失败，检查网络并重新载入。

### 为什么导出按钮没有生成文件？

先确认场次已经结束，并检查浏览器是否拦截下载。只有已完成场次支持导出。

### 教师忘记密码怎么办？

联系管理员重置密码。旧会话会失效，新临时密码只显示一次；教师下次登录必须设置新密码。

## 6. 建议的日常操作流程

管理员在教师入职或首次使用前创建账号并安全交付一次性凭据；教师首次登录后立即改密。教师在学期开始时创建课程和班级，通过模板导入名单并处理校验结果。每次上课从工作台核对班级人数后开始点名，等待所有变更同步并确认无待确认学生后结束场次。课后从考勤记录核对异常、填写原因修正，最后按需导出 Excel 或 CSV 留档。
