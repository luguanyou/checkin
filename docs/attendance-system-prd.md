# 智能课堂考勤系统 PRD

## 文档信息

| 项目 | 内容 |
| --- | --- |
| 文档状态 | 待评审 |
| 版本 | v1.0 |
| 目标平台 | 桌面端 Web 浏览器 |
| 主要使用者 | 任课教师、教务/管理员 |
| 本期范围 | 课程点名、名单管理、异常修正、考勤导出 |

## 1. 概述

本系统面向高校教师，提供从选择课程/班级、导入学生花名册、课堂逐一语音点名，到课后异常修正和期末数据导出的完整考勤闭环。系统采用“默认已到、仅处理异常”的方案 A，结合浏览器原生语音播报、键盘/翻页笔快捷键和本地进度恢复，降低教师点名操作成本，保证课堂过程不受网络波动影响，并为平时成绩计算提供可靠数据。

## 2. 背景与问题

### 2.1 用户问题

- 教师使用纸笔或表格点名，记录和统计耗时，容易漏记或错记。
- 逐一确认学生状态时需要频繁操作鼠标，无法在讲台上保持连贯授课。
- 缺勤、迟到和请假记录在课后修改成本高，容易造成整表重复查找。
- 学期末需要手工汇总应到、实到、迟到、请假、缺勤次数并换算平时分。
- 网络不稳定或页面意外关闭可能导致课堂记录丢失。

### 2.2 产品目标

1. 将一次课堂点名转化为可连续执行的“播报-按键-自动下一位”流程。
2. 支持名单快速导入、校验、确认和标准化导出。
3. 让教师可在异常名单中直接修正缺勤/迟到状态。
4. 在不依赖持续网络请求的情况下保障点名过程和进度可恢复。
5. 输出可用于教务留档和期末平时分计算的明细与汇总数据。

## 3. 用户与角色

### 3.1 任课教师（主要角色）

- 目标：快速、准确完成课堂点名，并在课后处理特殊情况。
- 典型场景：单手使用键盘或蓝牙翻页笔，另一只手进行课堂教学。
- 核心任务：选择课程/班级、确认花名册、点名、修正状态、导出结果。

### 3.2 教务/管理员（次要角色）

- 目标：维护课程和班级基础数据，查看或导出学期考勤结果。
- 本期重点：使用教师端已有的导入/导出能力，不扩展复杂权限和审批流程。

## 4. 产品范围

### 4.1 本期包含

- 课程/班级选择。
- 学生名单导入、字段校验、重复学号处理和导入确认。
- 逐一语音点名及状态快捷键。
- 预录请假状态联动。
- 实时异常名单与课后一键修正。
- 单次点名表、学期汇总表、平时分换算导出。
- 本地缓存、断网可用、意外关闭后的进度恢复。

### 4.2 本期不包含

- 人脸识别、定位打卡、自动识别学生声音。
- 学生端自主签到及复杂请假审批流。
- 移动端原生 App。
- 与校园统一身份认证、教务系统的强耦合对接（可作为后续集成）。

## 5. 核心用户流程

```text
[教师登录]
    -> [选择课程/班级]
    -> [导入或确认学生花名册]
    -> [进入点名界面]
    -> [逐一语音播报 + 快捷键标记]
    -> [课后异常名单修正]
    -> [导出单次记录/期末汇总/平时分]
```

### 5.1 点名主流程（方案 A）

1. 教师进入某课程某班级的本次点名页面，所有学生初始状态为“已到（待确认）”。
2. 教师点击“开始点名”或按 `Space`，系统播报当前学生姓名。
3. 教师根据现场情况按快捷键标记状态，系统保存该状态并自动播报下一位。
4. 教师可按 `Backspace` 或 `Up` 回退到上一位，重新播报并修正。
5. 全部学生处理完成后，教师点击“结束点名”；系统提交本次记录并保留可导出数据。

## 6. 功能需求

### 6.1 课程与班级选择

**FR-01** 系统应展示当前教师可操作的课程和班级，至少包含课程名称、学期、班级名称。

**FR-02** 教师选择课程/班级后，系统应展示最近一次点名时间及是否存在未完成的本地草稿。

**FR-03** 未确认花名册时不得进入正式点名；若没有学生记录，应提供导入入口和模板下载入口。

### 6.2 学生名单导入

**FR-04 标准模板** 系统提供 Excel 模板，字段为：`学号*`、`姓名*`、`性别`、`班级*`、`专业`。带 `*` 字段为必填。

**FR-05 格式支持** 支持 `.xlsx`、`.xls`、`.csv` 文件导入，并在选择文件时校验扩展名和可解析性。

**FR-06 数据校验**

- 缺少学号或姓名的记录禁止导入，并在预览列表中高亮具体行和字段。
- 学号在文件内或系统已有名单中重复时，显示重复数量和冲突记录。
- 对重复学号提供“覆盖已有记录”和“跳过重复记录”两种处理方式，教师确认后执行。
- 导入前展示有效记录数、错误记录数、重复记录数和最终待导入记录数。

**FR-07 导入确认** 教师确认后才写入当前课程/班级名单；导入结果应提示成功、跳过和失败数量，并允许下载错误明细。

**FR-08 名单版本** 系统应保留本次点名所使用的名单快照，后续名单变更不得修改已完成点名的历史学生集合。

### 6.3 逐一语音点名

**FR-09 初始状态** 进入点名界面时所有学生显示为“已到（待确认）”，当前索引默认为第一位。

**FR-10 开始/暂停/结束**

- “开始点名”触发当前学生播报；重复触发不得重复创建未结束的语音队列。
- “暂停”停止自动推进并暂停/取消当前播报，恢复后从当前学生继续。
- “结束点名”需二次确认；确认后保存结果，取消则返回点名界面。

**FR-11 状态与快捷键**

| 状态/操作 | 键盘快捷键 | 翻页笔映射 | 结果 |
| --- | --- | --- | --- |
| 已到 | `Space` / `Enter` | `PageDown` / `Next` | 记录已到，进入下一位 |
| 缺勤 | `1` / `Numpad 1` | `Down` | 记录缺勤，进入下一位 |
| 请假 | `2` / `Numpad 2` | 未指定 | 记录请假，进入下一位 |
| 迟到 | `3` / `Numpad 3` | 未指定 | 记录迟到，进入下一位 |
| 回退 | `Backspace` | `PageUp` / `Prev` | 返回上一位并重新播报 |

快捷键只在点名页面且未聚焦文本输入框时生效。最后一位处理完成后不得越界，应显示“已完成”状态。

**FR-12 视觉反馈** 标记状态后，当前学生卡片及对应列表项应显示状态颜色和短暂反馈：已到为绿色、缺勤为红色、请假为黄色、迟到为蓝色。颜色不能作为唯一信息，必须同时显示文字标签。

**FR-13 点名总览** 页面应显示当前课程/班级、当前进度（如 `15/45`）、当前学生姓名、学号、状态，以及全班已处理列表。

### 6.4 TTS 语音设置

**FR-14 引擎** 使用浏览器原生 `Web Speech API`；浏览器不支持或调用失败时，应提示原因并允许关闭语音继续手动点名。

**FR-15 设置项**

- 语速：`0.8x`、`1.0x`、`1.2x`、`1.5x`。
- 文本模板：`[姓名]` 或 `下一位，[姓名]`。
- 声音：从系统可用普通话音色中选择男女声；若系统无匹配音色，回退到默认中文音色。

**FR-16 请假播报** 当前学生若存在课前请假记录，界面显示“已请假”卡片，语音播报“[姓名]，请假”。教师按 `Space` 可直接确认并进入下一位；仍允许通过回退修正。

### 6.5 异常名单与课后修正

**FR-17 实时异常名单** 右侧挂起面板仅显示本次课堂被标记为“缺勤”或“迟到”的学生，并显示姓名、学号、当前状态。

**FR-18 一键修正** 教师可在异常名单中将学生直接改为“迟到”或“已到”。修正应立即更新主列表、统计数字和本地草稿，并记录最后修改时间。

**FR-19 修正审计** 每次状态修改应保留原状态、目标状态、修改人和修改时间，至少支持在当前页面撤销最近一次修正。

### 6.6 导出与成绩换算

**FR-20 单次点名表** 支持按课程、班级和日期导出完整记录，字段至少包括：姓名、学号、班级、签到状态、点名时间、最后修改时间。

**FR-21 学期汇总表** 按课程/班级汇总学生明细，并自动统计：总应到次数、实到次数、迟到次数、请假次数、缺勤次数。

**FR-22 平时分换算** 默认公式为：

```text
Score = 100 - (缺勤次数 × 5 + 迟到次数 × 2)
```

扣分权重应支持课程级自定义；分数下限默认为 0 分，导出时同时保留原始次数、权重和最终分数，确保结果可追溯。

**FR-23 导出格式** 至少支持 `.xlsx` 和 `.csv`；导出文件名应包含课程、班级、日期/学期和报表类型。

## 7. 数据与状态规则

### 7.1 状态定义

| 状态 | 含义 | 是否计入实到 | 是否计入异常 |
| --- | --- | --- | --- |
| 已到 | 学生正常到课 | 是 | 否 |
| 缺勤 | 点名时无人应答且未请假 | 否 | 是 |
| 请假 | 课前已审批或预录请假 | 否 | 否 |
| 迟到 | 点名时未到、课后到场补签 | 是 | 是 |
| 待确认 | 进入点名后的临时默认状态 | 待最终状态 | 否 |

同一学生同一堂课只能有一个最终状态。回退和修正应覆盖当前状态，但不得改变历史课堂记录。

### 7.2 本地缓存与提交

- 点名状态、当前索引、TTS 设置和名单快照应写入 `localStorage` 或等价本地存储。
- 每次状态变更后立即保存草稿，不依赖点击“结束点名”。
- 页面重新打开时，若存在未完成草稿，提示“恢复上次点名进度”，展示课程、班级、保存时间和恢复/放弃选项。
- 点名过程允许离线进行；结束时优先异步提交，失败时保留待同步状态并提供重试。

## 8. 非功能需求

### 8.1 性能与兼容性

- 点名过程不应因单次状态切换发起阻塞式 HTTP 请求。
- 在 Chrome 80+、Edge 80+、Safari 14+ 上验证核心流程和 `SpeechSynthesis` 能力。
- 课堂名单加载后应可在无网络情况下完成点名和本地导出（浏览器能力允许时）。

### 8.2 易用性与可访问性

- 全程支持无鼠标操作；焦点顺序清晰，快捷键有可视化状态反馈。
- 颜色需配合文字、图标或标签，满足色觉差异用户识别要求。
- 语音不可用时，所有信息仍可通过文本和键盘操作完成。

### 8.3 数据安全

- 教师只能访问授权课程/班级数据。
- 导出前显示数据范围确认，避免误导出其他班级名单。
- 本地缓存应按教师、课程、班级和点名场次隔离；退出登录后应清理可配置的敏感缓存。

## 9. 成功指标与验收标准

### 9.1 指标

上线前建立基线，上线后按课程/班级分层观测：

- 核心指标：一次课堂点名完成率、点名平均耗时、状态修正率。
- 体验指标：快捷键操作占比、TTS 成功播报率、意外关闭后的恢复成功率。
- 数据指标：导入失败率、导出成功率、离线草稿丢失率（目标为 0）。

### 9.2 关键验收场景

1. 导入缺少学号或姓名的文件时，系统阻止导入并高亮错误行。
2. 存在重复学号时，教师可分别验证“覆盖”和“跳过”的结果。
3. 使用 `Space`、`1`、`2`、`3` 完成一轮点名，状态、进度、异常名单均正确更新。
4. 使用 `Backspace` 回退并修改状态后，列表和导出数据只保留修正后的最终状态。
5. 课前请假学生被点到时，界面标识“已请假”，语音播报正确，按 `Space` 可跳过。
6. 刷新或关闭页面后恢复草稿，当前学生索引和已标记状态与关闭前一致。
7. 无网络情况下完成点名，恢复网络后可提交；提交失败时数据可重试且不重复创建记录。
8. 单次报表、学期汇总和平时分报表的字段、次数和公式结果准确可复核。

## 10. 依赖、风险与应对

| 项目 | 风险/依赖 | 应对 |
| --- | --- | --- |
| 浏览器 TTS | 不同系统音色、权限和发音效果不一致 | 提供音色回退、语音开关和文本操作兜底 |
| 文件解析 | `.xls` 和异常 CSV 编码导致解析失败 | 导入预览、错误明细、编码探测和示例模板 |
| 本地存储 | 浏览器清理缓存或多标签页并发覆盖 | 版本化草稿、保存时间提示、提交前冲突检查 |
| 网络同步 | 结束时请求失败或重复提交 | 客户端幂等标识、待同步队列和重试机制 |
| 误操作 | 快捷键误触导致状态错误 | 当前状态反馈、回退、修正审计和结束前确认 |

## 11. 开放问题

1. 教师登录方式和课程/班级数据来源是什么，是否需要对接统一身份认证或教务系统？
2. “覆盖已有记录”是否需要二次确认，覆盖范围是当前课程还是全局学生档案？
3. 请假记录来自哪个模块，审批状态以何种字段作为有效依据？
4. 平时分权重是否需要按不同考勤状态分别配置，分数下限和小数位规则是否固定？
5. 学期汇总中“应到次数”是否扣除请假场次？建议在评审时确认统计口径并固化为系统规则。
6. 是否需要操作日志查询、报表打印和管理员批量导入等二期能力？

## 12. 版本规划建议

- **MVP**：课程/班级选择、名单导入校验、方案 A 点名、快捷键、TTS、异常名单、本地恢复、单次导出。
- **V1**：学期汇总、平时分自定义权重、离线待同步、修正审计、管理员数据维护。
- **后续版本**：统一身份认证/教务系统集成、学生端签到、请假审批、移动端适配和更丰富的统计分析。
